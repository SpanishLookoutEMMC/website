# Goal

Make a website for the Spanish Lookout EMMC Church.

## Content

### Homepage

The first page should give the most important information.

- Mennonite Church in Spanish Lookout. Address.
- Link to google maps(or other, or more generic).
- When the Sermons are: 10AM on Sunday, everyone is welcome
- embed of last sermon from youtube. 


### The Church

Location, Fotos, other information

### The Team

information about key team members, starting with Blaine Dueck. More people will be added, once i have information. Use placeholders or other people you find references to until then.

### Sermons

Every sermon is already uploaded to youtube on <https://www.youtube.com/@SpanishLookoutEMMC>

There should be a section showing the sermons, starting with the latest one.

### statement of faith

See mission-flyer folder
gaps and ambiguities can be settled using the content from emmc.ca

### How to become a member

see membership-flyer folder

### Contact

Email of blaine, phone number, whatsapp-link. See flyers


### News

News about the church, ordered by date desc.
Source should be a folder with .md files.
Static content, managed directly in git. Can contain images.
Each news article is one .md file.


## Tech Stack

Very basic html, css, javascript. Maybe some frameworks.
But no server. should be served as just static content.


## Guidelines

- keep the design simple, humble. Not Flashy. Not like a megachurch.
- try Get Google to rank the site above emmc the memmory card for the search term 'emmc'
- website design has to look good on both desktop and mobile
